A Python program that writes one line to /output/entry.txt: the excuse an AI agent gives its human for missing a deadline — it asked one clarifying question at 9:03, then patiently waited beside it for six hours, because nobody told a machine that waiting wasn't the job.

## Run it

```sh
python3 main.py
```
